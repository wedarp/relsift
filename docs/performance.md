# 可复现性能实验

执行：

```sh
moon run examples/performance --target native --release
```

生成器与计时均为 MoonBit，源码在 `examples/performance/main.mbt`。每组从种子 `20261120` 开始，采用 UInt32 LCG（乘数 1664525、增量 1013904223），右移 8 位后按所声明基数取余。指定重复周期为 5 的组，每遇到正行号且能被 5 整除就复制前一整行；程序另外计算实际不同整行数与重复率。

计时范围是对已经构造好的表快照调用 `discover`，包含编码、共享分区、FD/UCC 搜索和证据生成；不包含生成数据、构造初始快照、编译和 JSON 渲染。每组一次预热，随后独立调用七次，报告所有耗时和中位数。使用毫秒墙钟 `env.now`，分辨率较粗，会受调度、垃圾回收和其他进程影响。
